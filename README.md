# Digital Neuromotor Assessment & Adaptive Biofeedback Platform

Geriatrik nöroloji hastaları için geliştirilmiş; ince motor kontrolü (Finger Tapping) analiz eden ve yorgunluk indeksini hesaplayan dijital platform.

## 🚀 Özellikler
- MediaPipe ile Renksiz El Takibi
- Dijital Yorgunluk İndeksi (Fatigue Index) Hesaplama
- Ön Test / Son Test Klinik Değerlendirme

## 🛠 Dosyalar
- `main.py`: Ana Python kodu
- `requirements.txt`: Gerekli kütüphaneler
